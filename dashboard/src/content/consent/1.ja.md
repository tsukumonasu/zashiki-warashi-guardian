# 顔の登録についてのお知らせ

写真を追加する前に、必ずお読みください。登録してよいのは、写真に写っている本人、またはその親や保護者だけです。

人形は、家族を迎え、見知らぬ人を警戒できるように、訪れた人の顔とあなたが登録した写真を照らし合わせます。そのために、写真を1枚あなた自身の AWS アカウントに送ります。写真はいったん一時的な保管場所に置かれ、その後削除されます。残るのは、Amazon Rekognition のコレクションに保存される数値の顔ベクトルと、あなたが入力した表示名だけです。登録が終わったあと、写真そのものは残りません。

人形が見知らぬ人に家族の名前を言ったり見せたりすることはありません。ゲストと審査員のアカウントは、登録された顔や名前を見ることができません。

このページでいつでもメンバーを削除できます。削除すると、顔ベクトルとメンバーの記録が消えます。

チェックボックスに印を付けることで、写真に写っている本人がこの利用に同意していることを確認したものとします。
